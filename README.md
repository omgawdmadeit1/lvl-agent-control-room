# LVL Agent Control Room

Multi-agent ops console for [lvlltd.com](https://lvlltd.com): focus-four board, live scout (server-proxied), site health scoring, backpressure, swarm topology, and WCAG tooling.

## Scripts

- `npm run dev` — local control room
- `npm run build` — Vercel production build
- `npm run typecheck` — TypeScript

## Stack

TanStack Start · React 19 · Vite · Tailwind · Zustand
